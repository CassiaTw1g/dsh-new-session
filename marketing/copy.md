# 模型说开不了新对话，我把它做出来了

## 正文

前几天在 DSH 里干活，做到一半想让模型自己开一段新对话接着做，就打了句「新开一段，把剩下的收尾做完」。它回我：新对话我开不了，那是界面操作，你得自己点左侧栏。当时真的有点窝火😅，明明一句话能说清的事，还得我手动切过去，再把前情复述一遍，来回两次就不想干了。

说实话我第一反应是：那我自己写一个。翻了 DSH 的会话接口，写了这个插件 dsh-new-session。装完再去说「新开一段，把 X 做完」，模型真的自己把会话建出来了，我一下都没点。结果装完第一天，我基本没再碰过左侧栏。

最爽的是三点连在一起：

一，真的只要一句话。它自己建会话、自己把活接过去，不用我去左侧栏找按钮，和 codex 里说一句就新开一段是同一个手感。

二，自带上下文交接。上一段对话会以 dsh-session: 的只读快照带进新会话，我不用再把背景重讲一遍，省下来的其实是最烦的那部分。

三，自动切到新对话。结果落地后 Web UI 直接跳过去，卡片也能点；超过 3 分钟或者翻历史的时候，它不会突然把你的视图抢走。

几个我自己比较在意的细节：新会话落在当前工作区，侧边栏里就能看见，不是建完就找不着的孤儿会话；标题用 user 来源钉住，不会被自动标题盖掉；宿主那半边零 @deepseek-ai/* import，不挑宿主小版本。16 组单测都过了，MIT，随便看。

装就一行：

node tools/install-profile.mjs --profile desktop

开源在 https://github.com/CassiaTw1g/dsh-new-session ，用得上就拿走，遇到问题直接提 issue 🚀
